Token Radar ranks the pre-token protocols in the DefiLlama snapshot by implied value: TVL times a live-market sector multiple, times seven-day growth, times the time run with no token. It scores 226 protocols — the 40-protocol watchlist plus 186 below the $50M floor — and ships a sortable, filterable dashboard with a per-protocol farm plan and a model panel that shows the arithmetic behind every number.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
